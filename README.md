# MUSE GANTT

iPhone で使う、ガントチャート型のタスク・工程管理アプリ。（アプリ内のMUSE機能は削除しました）

## 画面

- 上部：日付（‹ › で移動、タップで日付選択）・日／週／月／大日程の切り替え
- 中央：ガントチャート（画面の約85%）。行ごと・日ごとに区切り線があります。ページ全体は縦にも横にもスクロールしません。タスクが多いときだけチャート内が縦にスクロールし、ピンチで拡大したときだけ横にスクロールします
- 下部：今日／一覧／＋／勤怠（出退勤・月ごとの勤怠表と残業）／設定
- 詳細・追加・一覧・設定は画面中央のカードで開き、外側をタップすると閉じます

## 表示の切り替え

| 表示 | 1列 | 使いどころ |
|---|---|---|
| 日 | 時刻（6:00–20:00） | その日の段取り。15分単位で動かす |
| 週 | 1日 | 月〜日。‹ › で1週ずつ送る。月をまたぐ週は前の月の週として「10月 第5週」のように表示。バーは日の枠いっぱいに出て、ドラッグすると1日ずつ動く（時刻はそのまま） |
| 大日程 | 1か月 | 1年分（初期値は4月始まり）を横スクロールなしで俯瞰。項目は月単位で入れて動かす |

- 大日程の「日予定」（日ごとのタスクも一緒に出すか）は、チャート左上で切り替えます
- 日・週・月・大日程とも、チャートの幅は画面幅にそろえています（拡大したときだけ横スクロール）
- ヘッダーと下のタブはどの画面でも共通。一覧・勤怠・詳細では、ヘッダーにページ名と操作ボタンが出ます
- 大日程の1年は設定の「1年の始まり」で決まります（初期値は4月＝年度）。‹ › で1年ずつ移動
- 縦の区切り線は日付・週の見出しから一番下まで通しています

## 操作

| やりたいこと | 操作 |
|---|---|
| 詳細を見る | バーかタスク名をタップ |
| 日時を動かす | バーを長押ししてドラッグ（日表示は15分単位、拡大すると5分単位。大日程は1か月単位） |
| 所要時間を変える | 選択中のバーの両端のつまみをドラッグ |
| 拡大・縮小 | チャートをピンチ（日表示は拡大に応じて目盛りが1時間→30分→15分） |
| 完了／戻す | タスク名左の丸をタップ |
| 開始・中断・再開 | 詳細シートのボタン（実績の時刻を記録） |
| 追加 | ＋、または空いている所を長押し（その時刻・その日・その週、その行のプロジェクトで追加） |
| 大日程を追加 | ＋ →「大日程の節目」。開始月・終了月を選ぶか、「6月〜8月 据付」「5月 正式図面発行」と書く |
| 文章で追加 | 「明日 3号機 治具調整 45分」「金曜まで 報告書 2h 重要」など。時刻を書かなければ空き時間へ自動配置 |
| 取り消し | 変更直後のトーストの「元に戻す」 |

## 色と表示

- 深緑：通常 ／ 真鍮色：重要 ／ 赤：遅延・期限超過 ／ 灰：完了 ／ 青灰：プライベート
- バーの下の細い線が実績、赤い旗が期限、ひし形がマイルストーン（進捗率の表示はありません）
- 濃い灰の枠は大日程、四角いチェックは大日程の項目
- 薄い灰は勤務時間外・休日、赤い縦線は現在時刻
- 製造部門の休憩（初期値 10:15–11:00）はチャートには出さず、工程調整・改造の自動配置にだけ使います

## 休み・休日出勤・振替

週・月表示で日付の見出しをタップ（日表示は左上の「平日／休日」ボタン、または「勤怠」→「今日の区分」）すると、次の4つをワンタップで登録できます。

| 区分 | 登録できる日 | 自動配置 |
|---|---|---|
| 休み | 勤務日 | 仕事を入れない |
| 振替休日 | 勤務日 | 仕事を入れない。振替出勤と1日ずつ対応 |
| 休日出勤 | 休日 | 勤務時間に仕事を入れる。時間は休日出勤として集計 |
| 振替出勤 | 休日 | 勤務時間に仕事を入れる。あとで振替休日が1日必要 |

振替出勤と振替休日は日付順に1対1で対応させ、数が合わないと「勤怠」に赤い点が付き、「振替休日があと◯日足りません」「振替出勤のない振替休日が◯日」と表示します。「勤怠」の「振替」で対応表を確認できます。

## 作業可能条件（設定で変更可）

- 通常勤務 8:30–17:30（平日）
- 工程調整・改造／設備停止：製造部門の休憩中か休日だけ
- 休日作業：休日の勤務時間帯
- 工場カレンダーの休日を追加可能
- 勤務予定と、実際の出退勤（実績タブ）は別々に記録し、時間外・休日出勤を集計

ドラッグで条件外に置こうとすると確認が出ます。前工程より先に置いた場合や期限を超える場合は通知し、後続タスクと重なると「後続を調整」で条件を満たす次の空き時間へ自動で移せます。

## 2つの動かし方

### 1. claude.ai のアーティファクト（推奨）

- データは claude.ai 側のデータベースに保存され、同じアカウントでサインインした端末間で同期します（読み書きできるのは所有者と編集者だけ）
- オフライン時は直前のデータを表示し、変更は端末にも保存します

### 2. このリポジトリ（GitHub Pages など）

- `index.html` をそのまま配信すると、ホーム画面に追加できる PWA として動きます（`sw.js` でオフライン起動）
- データはその端末のブラウザ内だけに保存されます（同期なし）

外部のエージェントや API と接続するときは、この関数群を呼べばチャートと同じデータ・同じ制約チェックを通ります。

## データ

各タスクは次を持ちます：`id, name, project, kind, scale（time=日・時刻、week=大日程）, start, end（予定）, segs（実績の開始/終了の区間）, progress, status, priority, important, deadline, deps（前工程）, milestone, assignee, memo, history（変更履歴と理由）, rev, updatedAt`。

ほかに `meta/settings`（勤務条件）、`attendance/YYYY-MM`（出退勤）。設定の「全データをコピー」で JSON を取り出せます。

## 実装範囲と制約

- 同時編集はタスク単位で後勝ち
- 音声入力は iPhone のキーボードのマイクを使います（ページ内の音声認識はアーティファクトでは使えません）
- Google カレンダー等との連携は未接続です。日時はすべて時刻値で持ち、同期処理を足せる構造にしています
- リマインド通知は未実装です

`app.html` を変えたら `python3 build.py` で `index.html` を作り直します。次の項目を iPhone SE／15／15 Pro Max の Safari 表示・ホーム画面表示（計6サイズ）で自動確認しています。

- ページ全体の縦横スクロールが出ない（空・日・週・月・詳細シート・40件表示）
- チャートが画面の84〜89%を使う
- バーの左右端が時刻目盛りと1px以内で一致（再読み込み後も）
- 長押しドラッグで1時間移動、端のつまみで+30分 → 保存 → 再読み込み後も保持
- ピンチで×3まで拡大し、チャート内だけ横スクロール
- 空き部分の長押しで追加シート（指を離したときの誤タップなし）、文章からの自動配置

## 勤怠

下のタブ「勤怠」で、今日の出勤・退勤を「今」ボタンで記録し、1か月の勤怠をスクロールなしで確認できます。

- 上段：出勤日数・労働時間・残業合計・休日出勤の月合計（右上の ‹ › で月を切り替え）
- 表：1日〜末日を左右2列に並べ、各日の「出勤–退勤」と、その横に残業時間（赤、残業なしは0.0）／休日出勤（茶）を表示。今日の行は薄いピンク。行を押すとその日の勤怠ページで出退勤と区分を修正できます
- 時刻を入れると、画面を作り直さずにその場で残業と合計が更新されます
- 計算：労働時間＝退勤−出勤−休憩1時間（6時間以上の日）。標準勤務は8:30–17:30＝8時間で、超えた分が残業。休日（振替出勤を除く）の勤務は休日出勤として集計
- 休憩の長さは「設定 → 勤務」で変更できます

## 表示

下のタブ「設定 → 表示」で、フォント7種類と文字の大きさ5段階（極小・小・中・大・特大）を切り替えられます。文字の大きさはガントチャートと一覧の両方に反映されます。

「今」の位置は全表示で薄いピンクの塗りつぶしで統一しています（日＝今の1時間、週＝今日の列、大日程＝今月の列。見出しのマスごと塗ります）。休み・振替休日は赤の斜線、休日出勤は茶、振替出勤は緑で列ごと色が付き、見出しには色付きのバッジ（休み・振休・休出・振出）が出ます。

## バーの操作

- バーを1回タップ：選択（両端に白いつまみ）。つまみをドラッグで期間を伸び縮み、長押しで移動
- 選択中のバーをもう一度タップ（または左の項目名をタップ）：詳細ページ
- ドラッグ中の日時は画面上部のヘッダー位置に大きく固定表示
- 実績は「一覧」の右上から開けます

## 完了したタスク

- 完了にするとガントチャートから消え、「一覧 → 完了」に完了日つきで移ります（直後の「元に戻す」で取り消し可）
- 完了タブで名前を押すと詳細（‹ で一覧に戻る）、丸を押すと未完了に戻ってチャートに再表示

## 大日程（節目）

- 週表示と同じツリー：大項目＝車種・プロジェクト（▼で折りたたみ）→ その下に節目（号試・図面発行・SOPなど）を1行ずつ。日々のタスクは出ません
- 折りたたむと、大項目の行に節目の◆だけが残ります（週表示の折りたたみとは別に記憶）
- 追加：大項目の「＋」、または＋ →「大日程の節目」。月単位で、開始月・終了月（◆は月）を選びます。入力欄の「5月 正式図面発行」「6月〜8月 据付」「2027/6 量産開始」も読み取ります（日付を書いてもその月になります）
- 表示中の年度にない節目は、その行の右端「→ 27/5」で該当の年度へ移れます

## 画面の戻り方・大日程の扱い

- 一覧・勤怠・設定から戻る、日/週/大日程を切り替える、しばらくしてアプリを開き直すと、今日（大日程は今年度）の表示に戻ります。タスク詳細を閉じたときは見ていた位置のまま
- 大日程は完了にできません（丸のボタンなし）。不要になったら詳細の「削除」ボタンで消します
- 「重複」の表示はなくしました

## 大日程の期間・マイルストーン／詳細画面

- 大日程は「期間（帯）」と「マイルストーン（◆）」のどちらでも置けます（追加画面と詳細の「種類」で切替）。どちらも月単位：期間は開始月〜終了月の月の枠いっぱい、◆はその月の列の真ん中。日付は選びません
- チャート内の◆・丸・矢印などの記号は、文字と同じくらいの大きさ
- タスク詳細：名前は2行まで表示、開始・終了は「日付＋時刻」に分けて入力、分類は折り返して全部見える、◆ボタンでマイルストーン。進捗率（％）の入力・表示はありません
