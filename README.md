# MUSE GANTT

iPhone で使う、ガントチャート型のタスク・工程管理アプリ。
タスクの追加・変更などの操作や更新は、本人の指示で **MUSE（秘書役の Claude）** が行えるようにしています（手順は [CLAUDE.md](CLAUDE.md)）。

- claude.ai 版（推奨・端末間同期）：https://claude.ai/artifact/7b8ctLAEMyqEsmPmCcGZDp
- GitHub Pages 版（PWA）：https://sprintershota01172-collab.github.io/muse-todo/

## 画面

- 上部：日付（‹ › で移動、タップで日付選択）・日／週／大日程の切り替え
- 中央：ガントチャート（画面の約85%）。ページ全体は縦にも横にもスクロールしません。タスクが多いときだけチャート内が縦に、ピンチで拡大したときだけ横にスクロールします
- 下部：今日／一覧／＋／勤怠／設定。ヘッダーと下のタブはどの画面でも共通
- **ページ**（一覧・勤怠・設定・実績）はヘッダーとタブの間に出ます
- **編集はすべて下から出るシート**（タスク・大日程の編集、追加、1日の勤怠、休み・休日出勤）。今の画面の上に重なり、下の画面は作り直さず止めたままなので、閉じると同じ位置・同じスクロールに戻ります
- シートの上端：左「キャンセル」（このシートで変えた内容を確認のうえ取り消して閉じる）、中央に何を編集中か、右「完了」（閉じる）。変更はその場で保存されます。外側をタップしても閉じます（追加シートは入力途中の内容を30分間保持）

## 表示の切り替え

| 表示 | 横軸 | 使いどころ |
|---|---|---|
| 日 | **時刻**（6時〜20時。見出しは「8時」） | その日の段取り。バーの中に「8:30–17:30」と時刻が出る。15分単位で動かす |
| 週 | 1日（日付と曜日） | 月〜日。‹ › で1週ずつ。ドラッグで1日ずつ動く（時刻はそのまま） |
| 大日程 | 1か月 | 1年分（初期値は4月始まり＝年度）。車種・プロジェクトごとの節目を月単位で |

## 操作

| やりたいこと | 操作 |
|---|---|
| 編集する | バーを2回タップ（1回目で選択、2回目で編集シート）か、左のタスク名・一覧の行をタップ。一覧から開いたときは「チャートで表示」でチャートへ移れます |
| 日時を動かす | バーを長押ししてドラッグ（日表示は15分単位、拡大すると5分単位。大日程は1か月単位） |
| 長さを変える | 選択中のバーの両端の白いつまみをドラッグ |
| 日・期間を選び直す | 詳細の「予定」で、日（タスク）か月（大日程）を**2タップ**：1回目＝始まり、2回目＝終わり |
| 大日程の期間をその場で変える | 大日程のチャートで、その行の**始まりの月→終わりの月**をタップ（画面は切り替わりません）。◆の行は同じ月を2回タップで移動 |
| 大日程に新しい帯を作る | 車種の見出し行で始まりの月→終わりの月をタップ → 名前を入れて「追加」 |
| 追加 | ＋、または空いている所を長押し |
| 拡大・縮小 | チャートをピンチ |
| 完了／戻す | タスク名左の丸をタップ（編集シートでは「完了にする」） |
| 開始・中断・再開 | 詳細のボタン（実績の時刻を記録） |
| 取り消し | 変更直後のお知らせの「元に戻す」 |

### 追加シート

- **タスク（日・時刻）**：名前、2週間分の日付（1タップ。もう一度で「自動」）、開始（自動／8:30／10:15 休憩／13:00／15:00）、分類、時間、プロジェクト。日付・開始が「自動」なら分類の条件に合う空き時間へ置きます。「明日 10時 治具調整 45分」のように書いても入ります
- **大日程（月）**：「期間（帯）」か「マイルストーン（◆）」を選び、**2年分の月**から選ぶ（期間は始まり→終わりの2タップ、◆は1タップ）。年度をまたぐ期間も画面を切り替えずに選べます（‹ › で1年ずつずらすことも可）。「6月〜8月 据付」「5月 図面発行」と書いても月が選ばれます
- 期間と◆は同じ表示の大きさ・位置で切り替わり、枠はずれません

## デザインの決まり（全画面共通）

- 文字：10.5 / 11.5 / 13 / 14 / 16 / 20px の6段階と、数値用18px。太さは 600 / 650 / 700 / 800 の4段階。編集中の名前は20px、数値（勤怠・実績）は18pxの太字で、目に入るべきものが一番大きい
- 高さ：選択チップ32px・入力欄38px・ボタン40px・項目の行46px・シート上端52px（iPhone SE では少し詰めます）
- 角丸：ラベル6px・入力欄と小ボタン10px・カードとボタン12px・シート16px。選択チップは丸
- 入力欄はカードの中で背景色だけ（枠線なし）。カードは細い線1本、影はシートとお知らせだけ
- 強い色は操作（深緑）・重要（真鍮色）・遅延（赤）だけ
- 動き：シートは下から0.3秒、ページは0.2秒のフェード、押したときは小さく縮む。「動きを減らす」設定では動かしません

## 色と表示

- 深緑：通常 ／ 真鍮色：重要 ／ 赤：遅延・期限超過 ／ 灰：完了 ／ 青灰：プライベート ／ 濃い灰：大日程
- バーの下の細い線が実績、赤い旗が期限、ひし形がマイルストーン。進捗率（％）は表示しません
- 「今」は薄いピンク（日＝今の1時間、週＝今日の列、大日程＝今月の列）。休み・休日出勤などの色が付いた日が今日のときは、ピンクの縦線で囲みます
- 休み・振替休日は赤の斜線、休日出勤は茶、振替出勤は緑。見出しにバッジ（休み・振休・休出・振出）

## 休み・休日出勤・振替

週表示で日付の見出しをタップ（日表示は左上の「平日／休日」ボタン、または「勤怠」）すると、休み／振替休日／休日出勤／振替出勤をワンタップで登録できます。振替出勤と振替休日は日付順に1対1で対応させ、足りないと「勤怠」に赤い点が付きます。

## 作業可能条件（設定で変更可）

- 通常勤務 8:30–17:30（平日）
- 工程調整・改造／設備停止：製造部門の休憩中（10:15–11:00）か休日だけ
- 休日作業：休日の勤務時間帯
- 条件外に置こうとすると確認が出ます。前工程より先・期限超過は通知し、後続と重なると「後続を調整」で次の空き時間へ移せます

## 勤怠

「勤怠」で今日の出勤・退勤を「今」で記録し、1か月の勤怠（出勤日数・労働時間・残業・休日出勤）をスクロールなしで確認できます。行を押すとその日の出退勤と区分を直せます。

## MUSE（秘書）からの更新

- claude.ai 版：MUSE がアーティファクトのデータベース（`tasks` コレクション）を直接更新し、開いている画面にその場で反映されます。MUSE が変えたときは「MUSEが「〜」を更新しました」と出て、「見る」でその項目へ移れます。履歴には「MUSE」と表示されます
- GitHub Pages 版：MUSE が `muse-data.json` を更新して `version` を上げると、次に開いたときに反映されます。**端末で後から変えた・追加した項目は消えません**（MUSE が新しく変えた項目だけ MUSE の内容になります）
- 日時は `"2026-11-09 08:30"`・ISO・ミリ秒のどれでも、大日程は `"2027-05"` のように月で、分類や状態は日本語の名前でも受け付けます。詳しくは [CLAUDE.md](CLAUDE.md)

## データ

各タスク：`id, name, project, kind, scale（time=日・時刻、week=大日程）, start, end, segs（実績）, status, priority, important, deadline, deps（前工程）, milestone, assignee, memo, history（変更履歴）, rev, updatedAt`。
ほかに `meta/settings`（勤務条件）、`attendance/YYYY-MM`（出退勤）。設定の「全データをコピー」で JSON を取り出せます。

## ファイル

- `app.html` … 本体（claude.ai 版として公開しているもの）
- `muse-data.json` … MUSE が更新するタスクデータ（GitHub Pages 版だけが読む）
- `index.html` … `python3 build.py` で `app.html` と `muse-data.json` から作る PWA 版
- `CLAUDE.md` … MUSE（Claude）向けの手引き
- `manifest.webmanifest`, `sw.js`, `icon*.png`, `icon.svg` … PWA 用

## 品質確認

`app.html` か `muse-data.json` を変えたら `python3 build.py`。iPhone SE／15／15 Pro Max の幅で次を確認しています。

- 指示書の9ステップ（一覧／勤怠／チャートから項目をタップ → 編集シート → 入力欄をタップ → 値を変更 → 完了 → 元の画面 → 続けて別の項目）で、毎フレーム計測して次を確認
  - 開く・入力欄を選ぶ・閉じるあいだ、ヘッダー・タブ・下の画面・一覧の行が1pxも動かない（ページのスクロールも0のまま）
  - 一覧のスクロール位置・勤怠の表の位置が戻ったときも同じ
  - 入力途中の値は画面の更新が入っても消えない。キャンセルは確認してから元に戻す
  - キーボード分の余白はシートだけが取り、下の画面の高さは変わらない
  - レイアウトシフト（CLS）が 0
- ページ全体の縦横スクロールが出ない（日・週・大日程・各シート・一覧・勤怠・設定、ライト／ダーク）
- 大日程：シートでの2タップ、チャート上の2タップ（行・見出し行）、◆の2回タップ移動
- 長押しドラッグ・端のつまみ → 保存 → 再読み込み後も保持
- MUSE の書き方（ISO・日付だけ・月・秒・日本語ラベル）の読み取りと、端末の変更を残す反映

- 音声入力は iPhone のキーボードのマイクを使います
